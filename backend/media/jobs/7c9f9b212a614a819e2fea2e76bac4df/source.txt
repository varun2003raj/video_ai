Title: Introduction to Python Programming

Python is one of the most popular programming languages in the world. It is widely used in web development, data science, artificial intelligence, automation, and software development. Python is known for its simple and readable syntax, making it an excellent language for beginners.

What is Python?

Python is a high-level programming language created by Guido van Rossum and released in 1991. It focuses on code readability and allows programmers to write programs with fewer lines of code compared to many other languages.

Why Learn Python?

There are several reasons why Python is a great language to learn:

Easy to read and write

Large community support

Used in many industries

Great for beginners

Powerful libraries and frameworks

Python is used by major companies such as Google, Netflix, Instagram, and Spotify.

Installing Python

To start using Python:

Go to the official website: https://www.python.org

Download the latest version of Python

Install Python on your computer

Open the Python interpreter or use an IDE like VS Code or PyCharm

Your First Python Program

The first program most beginners write is called the "Hello World" program.

Example:

print("Hello, World!")

This line of code tells Python to display the text Hello, World! on the screen.

Variables in Python

Variables are used to store data.

Example:

name = "Alice"
age = 25

Here:

name stores text

age stores a number

Data Types

Python has several basic data types:

String – text values

Integer – whole numbers

Float – decimal numbers

Boolean – True or False

Example:

name = "John"
age = 20
price = 10.5
is_student = True
Taking User Input

Python allows users to enter information.

Example:

name = input("Enter your name: ")
print("Hello", name)

This program asks the user for their name and prints a greeting.

Conditional Statements

Conditional statements help programs make decisions.

Example:

age = 18

if age >= 18:
    print("You are eligible to vote")
else:
    print("You are not eligible to vote")
Loops

Loops are used to repeat actions.

Example:

for i in range(5):
    print(i)

This loop prints numbers from 0 to 4.

Conclusion

Python is a powerful yet beginner-friendly programming language. Learning Python opens the door to many fields such as web development, data science, machine learning, and automation.

With consistent practice, anyone can learn Python and start building real-world applications.
